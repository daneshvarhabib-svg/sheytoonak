# Sheytoonak (شیطونک)

A landscape mobile game for Android and iOS, built with **Unity**. Seen from behind the player on a sunny street, you
kick a football at the windows of the brick building across the road by swinging your phone. The ball
bounces back off the wall and must touch the ground exactly once before your next kick. Breaking every
window of a building earns a medal; 8 buildings, 3 lives. Persian, right-to-left UI. Offline.

## Status

**Not built or played yet.** The repository holds the gameplay scripts, unit tests, design documents, a
placeholder prototype that builds its whole scene from code (grey boxes, a football, simple legs, an
English debug HUD) and a cloud build workflow for an Android APK. The code has **never been compiled**
and **no APK exists**: the cloud build needs Unity licence secrets that are not set yet. See
[`docs/MISSING.md`](docs/MISSING.md) and [`docs/ANDROID_PHONE_WORKFLOW.md`](docs/ANDROID_PHONE_WORKFLOW.md).

## Unity version

**Unity 6000.0.84f1** (Unity 6 LTS), pinned in `ProjectSettings/ProjectVersion.txt`. The cloud build uses
the matching GameCI image (`unityci/editor:ubuntu-6000.0.84f1-android-3`). Built-in render pipeline for the
prototype; the packages are listed in `Packages/manifest.json`.

## Opening the project (needs a computer)

1. Install Unity Hub and Unity **6000.0.84f1** with Android Build Support.
2. Open this folder as a project. Unity creates the remaining `ProjectSettings/` files, `Library/` and the `.meta` files.
3. Window > General > Test Runner > EditMode > Run All.
4. Menu **Sheytoonak > Create Prototype Scene**, open `Assets/_Generated/Prototype.unity`, press Play
   (keyboard: A/D move, hold and release Space to kick, Q/E aim).
5. Menu **Sheytoonak > Build Android APK** writes `Builds/Android/Sheytoonak.apk`.
6. Commit `Packages/packages-lock.json`, any new `ProjectSettings/` files and all `.meta` files (not `Assets/_Generated`).

Phone-only route: [`docs/ANDROID_PHONE_WORKFLOW.md`](docs/ANDROID_PHONE_WORKFLOW.md).

# شیطونک — سندِ طراحیِ بازی

نسخه‌ی ۱، ۲۹ مهر ۱۴۰۵. مرجعِ تصویری: `docs/reference/street-reference.png`.

## ۱. خلاصه

یه نفر تو پیاده‌روی یه خیابون وایستاده و توپِ فوتبال رو به نمای ساختمونِ روبه‌رو شوت می‌کنه. هدف اینه که شیشه‌ها رو بشکنه.

- **سه حالتِ شوت:**
  - توپ می‌خوره به دیوار و برمی‌گرده. وقتی برگشت، باید بذاره یک بار زمین بخوره و بعد دوباره شوتش کنه، مثلِ تنیس.
  - توپ شیشه‌ای رو می‌شکنه. امتیاز می‌گیره و توپِ بعدی جلوی پاش میاد.
  - توپِ برگشتی دو بار زمین می‌خوره. یه جون از دست می‌ده.
- **پیشرفت:** خونه‌به‌خونه از سرِ خیابون تا تهش جلو می‌ره (۸ ساختمون). همه‌ی شیشه‌های یه ساختمون بریزه = یه مدال.
- **رکورد:** تعدادِ کلِ شیشه‌های شکسته.
- **کنترل:** فقط حرکتِ گوشی.
- **پلتفرم:** اپِ اندروید و آیفون با Unity.

## ۲. دید و حال‌وهوا

| | |
|---|---|
| دوربین | اول‌شخص، از ارتفاعِ چشم و کمی رو به پایین. پایینِ صفحه پاها و کفش‌های بازیکن و توپِ جلوی پاش دیده می‌شه. بالای صفحه ساختمونِ اون‌ورِ خیابون |
| سبک | دقیقاً مثلِ تصویرِ مرجع: انیمه‌ی نیمه‌واقعی، عصرِ آفتابی، نورِ گرم، سایه‌ی برگ‌ها رو پیاده‌رو |
| ساختمون | نمای آجری با ردیف‌های پنجره‌ی قاب‌سنگی، پرده و گلدون. طبقه‌ی همکف مغازه‌ست، با ویترینِ روشن و سایه‌بونِ رنگی |
| پیش‌زمینه | پیاده‌رو و جدول، خیابون با خطِ‌چین، تیرِ چراغ‌برق، درخت، نرده |
| توپ | توپِ فوتبالِ واقعی، با چرخشِ دیدنی |
| گوشی | عمودی (portrait) |

هر ساختمون یه تصویرِ پس‌زمینه‌ی جداست، به همون سبکِ مرجع ولی **بدونِ آدم**. ساختمون‌ها با هم فرق دارن: رنگِ آجر، تعدادِ طبقه، نوعِ مغازه، رنگِ سایه‌بون. توپ، پاها، خرده‌شیشه و آدم‌ها سه‌بعدی یا اسپرایت روی این تصویر می‌شینن.

## ۳. قوانین

| اتفاق | نتیجه |
|---|---|
| شروعِ هر توپ | توپ جلوی پای بازیکنه و با جابه‌جا شدنش همراهش جابه‌جا می‌شه |
| شوت | توپ می‌ره سمتِ ساختمون |
| شوت قبل از رسیدن به دیوار دو بار زمین بخوره، یا وایسه و قِل بخوره | «نرسید»، ‎−۱ جون |
| توپ به دیوار یا مغازه بخوره | برمی‌گرده سمتِ بازیکن |
| توپِ برگشتی قبل از زمین خوردن ضربه بخوره | ضربه حساب نمی‌شه، پیغامِ «اول باید بخوره زمین» میاد |
| توپِ برگشتی یک بار زمین خورده باشه | شوت مجازه |
| توپِ برگشتی دومین بار زمین بخوره، یا بعد از اولین زمین خوردن قِل بخوره | ‎−۱ جون |
| توپ از کنارِ بازیکن رد بشه | ‎−۱ جون |
| توپ به پنجره‌ی سالم بخوره | شیشه می‌شکنه، ‎+۱ امتیاز، توپِ بعدی جلوی پا |
| توپ به پنجره‌ای بخوره که قبلاً شکسته | توپ می‌ره تو خونه. ۳۵٪ وقت‌ها صاحب‌خونه با عصبانیت پرتش می‌کنه بیرون و بازی ادامه پیدا می‌کنه (باز هم باید یک بار زمین بخوره). بقیه‌ی وقت‌ها توپ از دست می‌ره و ‎−۱ جون |
| توپ از رویِ بوم رد بشه | ‎−۱ جون |
| توپ از کنارِ خیابون بیرون بره | ‎−۱ جون |
| جون‌ها تموم بشه | بازی تمومه |
| آخرین شیشه‌ی یه ساختمون بشکنه | مدال، بعد راه رفتن تا ساختمونِ بعدی |
| آخرین شیشه‌ی ساختمونِ هشتم بشکنه | بردی |

- **جون:** ۳ تا. بینِ ساختمون‌ها پُر نمی‌شه.
- **امتیاز و مدال:** از ساختمونی به ساختمونِ بعد منتقل می‌شن.
- **رکورد:** بیشترین تعدادِ شیشه، روی خودِ گوشی ذخیره می‌شه.

## ۴. کنترل با حرکتِ گوشی

گوشی عمودی جلوی سینه نگه داشته می‌شه و صفحه رو به خودِ بازیکنه.

| حرکت | کار در بازی |
|---|---|
| جابه‌جا کردنِ گوشی به چپ و راست (یا کج کردنش) | بازیکن تو پیاده‌رو چپ و راست می‌ره تا به جای فرودِ توپ برسه |
| تابِ لبه‌ی پایینیِ گوشی به جلو، مثلِ پایی که ضربه می‌زنه | شوت |
| دامنه‌ی تاب (چند درجه چرخید) | قدرتِ شوت: هرچی بیشتر، توپ بالاتر به نما می‌خوره. خیلی زیاد بشه، از روی بوم رد می‌شه |
| کمی کج تاب دادن به چپ یا راست | جهتِ شوت |
| پیچوندنِ گوشی حینِ تاب | پیچِ توپ (توپ تو هوا قوس برمی‌داره) |

**نکته‌های مهم:**
- جابه‌جاییِ واقعیِ گوشی تو هوا با شتاب‌سنج کمی لغزش داره. برای همین حالتِ پیش‌فرض «ترکیبی»ه: کج کردن، بازیکن رو جابه‌جا می‌کنه و سُر دادنِ گوشی یه جهشِ کوتاه روش اضافه می‌کنه. تو تنظیمات «فقط کج کردن» و «فقط سُر دادن» هم هست.
- حینِ تابِ شوت، جابه‌جاییِ بازیکن قفل می‌شه تا تکونِ شوت بازیکن رو نپرونه.
- علاوه بر تاب، **جای برخورد** هم مهمه:
  - اگه توپ کمی سمتِ راستِ پا باشه، کمی به راست می‌ره.
  - بهترین ضربه وقتیه که توپ بعد از زمین خوردن تو ارتفاعِ حدودِ زانو باشه (حدودِ ۳۵ سانتی‌متر).
  - ضربه‌ی بد خطای جهت و قدرت داره.
- **کالیبراسیون (اولین اجرا و از تنظیمات):**
  1. «گوشی رو صاف نگه دار» → تعیینِ حالتِ صاف.
  2. «یه بار مثلِ شوت تاب بده» → گوشی محورِ ضربه و جهتش رو یاد می‌گیره، چون این‌ها از گوشی به گوشی فرق دارن.
- **حالتِ لمسی فقط برای تست:** انگشت رو بذاری، جای افقیش بازیکن رو می‌بره. یه کشیدنِ سریع به بالا شوت می‌کنه. تو ادیتور: A/D برای حرکت، نگه داشتنِ Space و ول کردنش برای شوت.

## ۵. توپ و فیزیک

- فیزیکِ واقعیِ Unity: جاذبه، جهش رو زمین، برخورد با نما.
- باد: نیرویی جانبی، که تو هر توپِ تازه بینِ دو عددِ همون ساختمون انتخاب می‌شه.
- پیچ: نیروی مگنوس از چرخشِ جانبی.
- **کمکِ برگشت:** وقتی توپ به نما می‌خوره، مسیرِ برگشتش ۸۵٪ طراحی‌شده‌ست و ۱۵٪ فیزیکی. اولین زمین خوردنش جاییه که بازیکن بتونه بهش برسه (۱٫۳ تا ۲٫۴ متر جلوتر، تا عرضِ مشخصِ هر ساختمون به چپ و راست). کارِ اصلیِ بازی همینه: رفتن به جای توپ و زدن سرِ وقت.

## ۷. صفحه‌ها

1. **شروع:** اسمِ بازی، «بازی»، رکورد، تعدادِ مدال‌ها، تنظیمات.
2. **کالیبراسیون:** دو قدمِ بخشِ ۴، با یه زمینِ تمرین که توپ داره.
3. **بازی (HUD):**
   - شیشه‌های شکسته (عددِ بزرگ)
   - ۳ جون به شکلِ ۳ توپ
   - «ساختمونِ ۳ از ۸» و «شیشه‌ها: ۴ از ۹»
   - فلشِ باد
   - دکمه‌ی توقف
4. **بینِ ساختمون‌ها:** مدال روی صفحه، بعد راه رفتن (دوربین تو پیاده‌رو جلو می‌ره) و تابلوی «پلاکِ ۱۸».
5. **باخت:** شیشه‌های این دور، رکورد، مدال‌ها، «دوباره».
6. **برد:** «کلِ خیابون رو ترکوندی!»
7. **تنظیمات:** کنترل با حرکت روشن/خاموش، نوعِ جابه‌جایی (ترکیبی / کج کردن / سُر دادن)، حساسیت، کالیبره‌ی دوباره، صدا، لرزش.

همه‌ی متن‌ها فارسی و راست‌به‌چپ‌ان.

## ۸. صدا، لرزش، افکت

- **صدا:**
  - ضربه به توپ: شدتش بسته به قدرتِ شوت
  - خوردنِ توپ به آسفالت و به آجر
  - شکستنِ شیشه (چند صدای مختلف)
  - دادِ صاحب‌خونه وقتی توپ رو پس می‌ده
  - صدای محیطِ خیابون
  - موسیقیِ مدال
- **لرزش:** هنگامِ ضربه (کوتاه)، شکستنِ شیشه (سه تقه) و از دست دادنِ جون (بلند).
- **افکت:**
  - خرده‌شیشه که رو پیاده‌روی اون‌ور می‌ریزه
  - گرد و خاک رو آجر جای برخورد
  - ردِ توپ برای شوتِ قوی
  - پرده‌ای که بعد از شکستنِ شیشه تکون می‌خوره
  - گاهی همسایه‌ای که از پنجره سرک می‌کشه
  - گربه‌ای که از لبه‌ی پنجره می‌پره

## ۹. تقسیمِ کار

| آماده است (`Assets/Scripts`) | کارِ Codex |
|---|---|
| تمامِ قوانین (`RallyRules`) + تستِ خودکار | ساختنِ پروژه و صحنه‌ی Unity |
| فیزیک و محاسبه‌ی شوت (`KickSolver`، `BallController`) | تطبیقِ دوربین با تصویر، پس‌زمینه‌ها |
| تشخیصِ حرکتِ گوشی (`MotionGestureDetector`، `MotionKickInput`) + کالیبراسیون | مدلِ پا و انیمیشنِ ضربه، مدلِ توپ |
| کنترلِ لمسی و کیبورد برای تست | ابزارِ علامت‌گذاریِ پنجره‌ها رو تصویر |
| نگاشتِ پنجره‌های تصویر به فیزیک (`BackdropWindowMapper`) | همه‌ی رابطِ کاربری، صدا، افکت |
| رویدادها برای ظاهر (`GameEvents`) | ساختِ نسخه‌ی اندروید و آیفون |

## ۱۰. سؤال‌های باز

- اسمِ بازی رو با توپِ فوتبال همون «شیطونک» نگه داریم؟
- فعلاً جدولِ امتیازِ آنلاین نداره و همه چیز روی خودِ گوشیه. اگه بخوای، سرور جداگانه لازم داره.
